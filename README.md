## 📌 About

This repository contains my **Data Structures & Algorithms Lab programs written in C**, organized according to the laboratory assignment sequence.

The repository is being developed **program by program**, with each implementation added as I complete and understand it.

The main goal is to build a clear and practical collection of implementations covering fundamental Data Structures, Algorithms, and problem-solving techniques.
